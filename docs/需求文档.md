# Echo 需求文档（PRD）

> 版本：v0.1 ｜ 更新日期：2026-09-11 ｜ 对应里程碑：M1 语音内核（已完成）

---

## 1. 项目背景与目标

**背景**：桌面 AI 伴侣类产品（如 Open-LLM-VTuber）把"能听、能想、能说、有形象"整合到本地运行，
但多数实现把语音链路写成一坨脚本，换模型要改代码，出了问题难定位。

**目标**：做一个**本地优先的桌面 AI 伴侣**，先把最容易出问题的实时语音链路做扎实——
组件可替换、配置可驱动、无模型也能测试、异常能自愈；在此之上再叠加 Live2D 形象与 agent 能力。

**参考对象**：Open-LLM-VTuber（参考其分层思路与 VAD/ASR 接口设计，代码自行实现）。

---

## 2. 范围

### 2.1 M1 范围内（已完成）

- 实时语音闭环：麦克风 → VAD 断句 → ASR 转写 → LLM 生成 → TTS 合成 → 播放
- 说话打断（barge-in）：回复播放期间用户开口即停止播放
- 多后端可切换：改 `conf.yaml` 一行切换 VAD/ASR/LLM/TTS 实现，业务代码零改动
- 无外部依赖可跑通：全部组件提供 mock 实现，离线、无声卡也能跑测试
- 多轮上下文与历史持久化
- 异常处理：缺依赖、缺模型、GPU 不可用均有明确提示或自动降级

### 2.2 M1 明确不做（避免范围失控）

| 不做的事 | 原因 | 归属 |
|---------|------|------|
| Live2D 角色渲染与表情 | 前端工作量独立，先保证语音内核正确 | M2 |
| 回声消除（AEC） | 需要 WebRTC/信号处理，当前用耳机规避 | M2 之后 |
| 流式 ASR / 流式 LLM / 流式 TTS | 先做对再做快，当前追求端到端正确性 | M2 |
| 多用户、服务化部署、鉴权 | 本地单机场景不需要 | 不在计划内 |
| 云端模型托管与计费 | 目标用户是本地使用者 | 不在计划内 |

## 3. 用户故事与验收

| 编号 | 用户故事 | 验收标准 |
|------|---------|---------|
| US-1 | 作为用户，我说一句话，Echo 能听懂并回答 | 16k 中文语音可转写；端到端延迟有实测记录 |
| US-2 | 作为用户，Echo 说话时我可以直接插话 | 播放中检测到人声 → 播放停止；打断响应受音频块粒度限制（512 采样 ≈ 32ms） |
| US-3 | 作为开发者，我想换识别/合成模型 | 只改 `conf.yaml`，`src/` 一行不动 |
| US-4 | 作为开发者，我想在没有模型和网络的机器上验证链路 | mock 后端跑通全链路 + 全部测试通过 |
| US-5 | 作为用户，我希望它记得刚才聊了什么 | 保留最近 N 轮；退出后可恢复（JSON 持久化） |
| US-6 | 作为用户，出问题时我要知道原因 | 缺依赖提示安装命令；缺模型提示路径；GPU 不可用自动降级 CPU |

## 5. 非功能需求

| 类别 | 要求 | 现状 |
|------|------|------|
| 延迟 | 端到端目标 < 2s（及格）/ < 1s（优秀） | 分段已测（ASR 5s 音频 ≈1.5s、TTS ≈1–2s）；端到端待补测 |
| 打断响应 | 目标 < 300ms | 受音频块粒度限制，理论 32ms + 检测防抖（≈0.1s） |
| 资源占用 | CPU int8 可跑；8GB 显存可选 GPU 加速 | CPU 已验证 |
| 可移植 | Windows 优先，Linux/macOS 可运行 | 依赖均为跨平台库 |
| 可测试 | 测试不依赖网络、模型、声卡 | 36 个用例全部 mock 化 |
| 可观测 | 关键节点有耗时统计与事件回调 | `on_event` 输出各阶段耗时 |
| 安全 | 密钥不落盘，从环境变量读取 | `ECHO_LLM_API_KEY` |
| 可扩展 | 新增后端不改动现有代码 | 注册表 + 装饰器 |

## 6. 验收方式

1. `python -m pytest tests -q` 全绿（当前 36 个用例）
2. `python main.py --mode check` 四个组件创建成功
3. `python main.py --mode asr --wav <中文录音>` 输出正确文本
4. `python main.py --mode tts --text "<中文>"` 生成可播放音频
5. `python main.py --mode console` 实机语音对话 + 插话打断

---

## 7. 里程碑与遗留

- **M1 语音内核**（已完成）：FR-1 ~ FR-10
- **M2 Live2D 形象**（进行中）：FR-12 ~ FR-13，含浏览器实时链路与口型驱动
- **M3 Agent 能力**：FR-14，工具调用 + 长期记忆 + 情感驱动表情

**已知遗留**：无 AEC（外放易自打断）、非流式（首字延迟高）、SenseVoice 后端未实测、
端到端延迟与内存占用缺完整基线。

## 8. 名词表

| 名词 | 含义 |
|------|------|
| VAD | Voice Activity Detection，语音活动检测，用于把连续音频切成"一句话" |
| ASR | Automatic Speech Recognition，语音转文字 |
| TTS | Text To Speech，文字转语音 |
| barge-in | 打断：用户在助手说话时插话，助手应立即停止 |
| AEC | Acoustic Echo Cancellation，回声消除 |
| mock 后端 | 假实现：不做真实计算，用于测试接口契约与编排逻辑 |
